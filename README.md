# konkordia-project_1-
first major solo project(konkordia)
A college interest matcher, with a simple agenda of matching users based on their skills, interests, department etc. Built with Flask, Python, and Firebase.
## Features
- Sign up and login with college email (Firebase Authentication)
- Create a profile with interests, hobbies, department, college year.
- Match with other students based on common interests
- Secure, privacy-first messaging between matched users(UPCOMING)
- Clean and responsive web UI

## Tech Stack
- Frontend: HTML, CSS, (optional: JS)
- Backend: Python, Flask
- Database & Auth: Firebase
- Version Control: Git & GitHub
